# Contributing

This repository tracks the packaged Codex Pet v2 asset. Keep changes focused on the pet package, documentation, or reproducible QA notes.

Before opening a pull request:

- keep `pet.json` and `spritesheet.webp` together;
- preserve `spriteVersionNumber: 2`;
- keep the atlas at `1536×2288` using `192×208` cells;
- avoid adding the original private reference image or generated intermediate files;
- include a short changelog entry for asset changes.

Visual changes should include an updated preview under `assets/` so reviewers can inspect the result without downloading the atlas.
